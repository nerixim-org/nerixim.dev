# JA exemplar candidates

Researched 2026-07-12. All URLs fetched and verified live; quotes are copied
verbatim from the fetched page (1–2 sentences each — no full-page copies here
for copyright reasons). `../../portfolios.md` (the earlier AI-drafted research
note) turned out to be mostly unusable on verification — `craftz.dog` is
English-language, `narumi.dev` and `miyasho88.com` no longer resolve,
`katsuma.tv` has no prose (pure resume table), and the `note.com/izumin5210`
profile has no visible bio text. None of those are included below; this list
replaces that draft.

Target register (from `voice/ja.md` / `docs/copy/ja-copy-workflow.md`): 一人称・直接的、
静かな自信、抽象語より具体、翻訳調を避ける、「支援」「越境」「橋渡し」のようなポジショニング語を避ける。

## Top 5 to actually use

For anchoring the judge, prioritize the ones closest to nerixim's actual genre
(senior full-stack freelancer, service/profile page, not a diary post):

1. **Katsuma Narisawa** (note.com/katsumanarisawa) — best match for "senior contractor, matter-of-fact" register.
2. **じゃけぇ / freelance-jak.com/profile** — only true profile/service page in the set; structurally closest to a nerixim.dev about page.
3. **noranuko13** — cleanest match for the exact phrasing style already codified in `voice/ja.md`.
4. **raki** — best model for stating a long, senior career plainly without inflating it.
5. **うえすと (westhouse_k)** — best model for "facts over adjectives" (stack, tenure, rate stated directly).
