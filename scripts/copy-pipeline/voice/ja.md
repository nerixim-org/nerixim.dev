# 日本語ボイスルール

docs/copy/ja-copy-workflow.md の要約 + portfolios.md の調査結果に基づく。

## 文体

- 一人称・直接的。「〜しています」「〜が中心です」の淡々とした報告調
- 静かな自信。実績は事実として置く、盛らない
- 抽象語より具体。「何をしているか」>「何を象徴するか」
- 日本のフリーランスエンジニアが自分の note / Zenn / 個人サイトに書く文章が基準

## 避ける

- 翻訳調: 英語の文構造・語順をなぞった文
- ポジショニング語: 「言語と市場をまたぐ」「越境」「橋渡し」「落とし込む」
- 「〜を支援しています」の多用(1回まで)
- 名詞の圧縮しすぎ(漢字8文字以上の複合名詞)
- 三部構成スローガン(「A、B、C。」「A×B×C」)
- 営業臭・マーケ臭のあるコピー

## 好ましい例

- 「日本を拠点に活動しています」
- 「Webアプリやバックエンド、インフラまわりまで見ています」
- 「新規立ち上げと既存システムの改善の両方に対応しています」
